## Prova först

Kör koden. Ändra `20` till `16` och kör igen. Vad skiljer?

```python-exempel
alder = 20
if alder >= 18:
    print("Du är myndig.")
print("Klart.")
```

## Så fungerar if

`if` betyder **om**. Efter `if` kommer en jämförelse, och sedan ett kolon `:`. Raderna som ska köras **bara om** jämförelsen är sann skrivs under, flyttade in ett steg (fyra mellanslag). Det kallas **indrag**.

- Raden `print("Du är myndig.")` körs bara om `alder >= 18` är `True`.
- Raden `print("Klart.")` har inget indrag. Den hör inte till `if`, så den körs alltid.
- Indraget är inte pynt: det är så Python vet vilka rader som hör ihop.

```ruta
rubrik: Du kanske känner igen det från Excel
text: |
  I Excel finns funktionen `OM`, till exempel `=OM(A1>=18; "Myndig"; "")`. `if` gör samma sak, men villkoret och det som ska hända står på egna rader. Prova **Stegvis** på exemplet och se att raden inne i `if` hoppas över när villkoret inte stämmer.
```

```forutsag
kod: |
  alder = 16
  if alder >= 18:
      print("Du är myndig.")
  print("Klart.")
svar: "Klart."
forklaring: "16 är inte minst 18, så raden inne i if hoppas över. Raden utan indrag körs ändå."
```

```forutsag
kod: |
  x = 5
  if x > 3:
      print("stor")
svar: "stor"
forklaring: "5 är större än 3, så raden inne i if körs."
```

## Din tur

```ovning
id: m3-if-varmt
uppgift: "Variabeln `temp` finns redan. Skriv ut `Varmt` om `temp` är större än 20."
start: |
  temp = 25
ratta: {utdata: "Varmt"}
ledtradar:
  - Du behöver en if med en jämförelse och ett kolon på slutet.
  - Raden som skriver ut ska ha indrag, fyra mellanslag.
  - "if temp > 20: på en rad, och på nästa rad (indragen): print(\"Varmt\")"
facit: |
  temp = 25
  if temp > 20:
      print("Varmt")
```

```ovning
id: m3-if-ratta-indrag
uppgift: "Koden har ett fel med indraget. Rätta det så att programmet skriver ut `Godkänd`."
start: |
  poang = 80
  if poang > 50:
  print("Godkänd")
ratta: {utdata: "Godkänd"}
ledtradar:
  - Läs felmeddelandet. Vilken rad gäller det?
  - Raden efter if ska flyttas in ett steg.
  - Sätt fyra mellanslag framför print.
facit: |
  poang = 80
  if poang > 50:
      print("Godkänd")
```

## Det här lärde du dig

- `if villkor:` kör raderna under bara om villkoret är sant.
- Raderna som hör till `if` är indragna med fyra mellanslag.
- Rader utan indrag körs alltid.
