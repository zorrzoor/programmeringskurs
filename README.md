# Programmeringskurs

En interaktiv nybörjarkurs i programmering och Python som körs helt i webbläsaren: inget att installera,
inget konto och ingen inloggning (man väljer bara ett namn, och framsteget sparas på det). Kursen riktar sig till vuxna utan IT-bakgrund som är vana vid Office och
databasprogram. Man skriver riktig Python, kör den direkt på sidan och ser steg för steg vad som händer.

Status: idé- och planeringsfasen. Börja med [docs/koncept.md](docs/koncept.md) (hur kursen ska se ut och fungera).
Arbetet följs i ärendena, med [#1](https://github.com/zorrzoor/programmeringskurs/issues/1) som översikt.

## Innehåll i repot

- `docs/koncept.md`: koncept, pedagogik, kursplan, teknik och arbetsplan.
- `docs/manuellt.md`: vad som behövs från ägaren (beslut, åtgärder i klustret och GitHub).
- `CONTRIBUTING.md` och `CLAUDE.md`: arbetssätt.
